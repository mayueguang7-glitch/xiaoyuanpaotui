# xiaoyuanpaotui

## 简介

校园跑腿小程序（微信小程序 + 微信云开发版），支持**本地演示模式**（零后端环境直接运行体验）与**微信云开发线上模式**。

本项目基于开源 MIT 项目 [yhyg2/shidi-campus-express](https://github.com/yhyg2/shidi-campus-express)（拾递 · 校园代取快递 v3.1.0）构建，完整保留原 [LICENSE](LICENSE) 与 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 核心功能

- **学生下单**：选择校区、快递驿站、包裹尺寸、件数与送达地址，实时报价、查看进度、确认收货与评价/投诉
- **代取接单（分包）**：接单大厅浏览脱敏订单、一键抢单、标记取件与送达、工作台管理在手单量
- **管理后台（分包）**：订单管理、代取资格人工审核、成员邀请码管理、动态定价、公告发布、投诉处理与 CSV 导出
- **零门槛结算**：采用线下结算，无需企业资质或微信支付商户号，个人微信小程序账号即可上线试用

## 快速开始（本地演示模式）

无需购买服务器，也无需提前开通云开发，直接运行即可点通完整流程：

1. 打开 **微信开发者工具**，点击「导入项目」，选择本项目根目录。
2. AppID 保持默认的测试号/游客占位值 `touristappid`（若开发者工具提示不支持游客模式，可点击旁边的「测试号」即可）。
3. 进入小程序后同意用户协议，即自动进入**本地演示模式**（数据保存在本地 Storage，可在「我的」页切换普通用户 / 代取 / 管理员身份体验全流程）。

## 切换到线上微信云开发

当你准备用自己的小程序真实上线试用时：

1. 在 `project.config.json` 中将 `appid` 替换为你的真实微信小程序 AppID（不要将真实 AppID 提交到公开仓库）。
2. 在微信开发者工具中开通「云开发」，复制环境 ID 填入 `miniprogram/config.js` 的 `CLOUD_ENV`。
3. 右键 `cloudfunctions/api` 目录，选择「上传并部署：云端安装依赖」。
4. 详细部署与初始化管理员步骤请参阅 [说明文档.md](说明文档.md) 与 [docs/导入与部署.md](docs/导入与部署.md)。

## 本地开发与检查命令

需要 Node.js 22+（无需在根目录执行 `npm install`）：

```bash
npm test           # 运行全部 60 项自动化测试
npm run check      # 校验页面、分包、路由、WXML 语法与核心同步一致性
npm run sync       # 修改 shared/core.js 后同步到小程序端和云函数端
npm run release:check  # 公开推送前检查是否意外混入 AppID/密钥等敏感信息
```
